# CPENT Preparation

An original, sanitized CPENT preparation repository built from the supplied CPENT exam guide and penetration-test report.

> **Authorized-lab use only.** This repository intentionally excludes CPENT challenge answers, flags, credentials, target IPs, exam screenshots, and copied confidential report wording.

## Focus

- Reconnaissance
- Enumeration
- Vulnerability validation
- Initial access
- Linux/Windows privilege escalation
- Credential security
- Active Directory
- Web security
- Binary analysis
- IoT security
- Lateral movement
- Pivoting and double pivoting
- Evidence collection
- Professional reporting

The supplied CPENT guide emphasizes a structured target database, scan tuning, continuous evidence collection, and a professional penetration-test report. The supplied report demonstrates attack chains across web, Windows/AD, Linux, binary, IoT, CTF-style targets, and segmented networks.

## Publishing rule

Before pushing anything to GitHub, remove:

- Real target addresses
- Credentials
- Tokens/keys
- Challenge flags
- Exam answers
- Exam screenshots
- Client/company confidential information

Write public notes in your own words and use placeholder lab addresses.

## Step-by-step command playbook

The `commands/` directory contains practical, placeholder-based workflows for recon, enumeration, Linux/Windows privilege escalation, Active Directory, web testing, pivoting, binary analysis, IoT/firmware analysis, evidence and reporting.

These notes intentionally use sanitized placeholders and do not reproduce exam-specific answers, flags, credentials, target addresses or confidential screenshots.
